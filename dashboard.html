How to use the map

This map shows where Kenya’s Verra-registered carbon projects are located so you can explore project and conservancy-level data.

  • NRT boundary (green outline) — Select it to see the whole Northern Kenya Rangeland Project.
  • Conservancies (solid green areas) — Select one to see that conservancy’s details in the side panel.
  • Other projects (Komaza, Boomitra, KCSA) — Select an area or marker to see that project’s details.
  • Layers — Use the control (top right of map) to turn layers on or off.
  • Legend — Colors are explained in the legend below the map.
  • Mobile — Pinch to zoom; tap a region to select it.
Where we get our data

CarbonWatch is a community-facing transparency platform for carbon project reporting in Kenya. We track Verra VCS projects across Kenya. Project-level data comes from the Verra Registry, project proponents (e.g. NRT Carbon Impact), and project documents. SMS/IVR, USSD, and manual entries feed the central repository; this dashboard is the front-end for description and analysis. Per-conservancy figures are shown where officially disclosed; otherwise N/A. Full sources.

Project summary

CarbonWatch tracks Verra-registered carbon projects across Kenya. Current pilot examples shown here include Northern Kenya Grassland Carbon Project (VCS 1468, proponent NRT; 1,993,075 ha, 14 conservancies), Komaza (VCS 2623), Boomitra Kenya (VCS 3340), and KCSA (VCS 5451). For official details and issuance records, see the Verra Registry.

USSD interface for feature phones

Standalone view of the USSD channel: dial a short code on a basic phone to request data from the central repository (carbon payment status, grievance follow-up, and similar prompts) with an instant SMS-style reply—useful for members without smartphones or data bundles.

How it works

Community members dial a short code (for example *123*44#) on any feature phone. The request is routed through the USSD gateway to the CarbonWatch application server, which queries the central repository and returns a short text response.

Why USSD?

USSD works on basic feature phones and does not require mobile data. This makes it ideal for conservancies where connectivity is limited but GSM coverage exists.

  • Accessible on any phone with a SIM card.
  • Works anywhere with network signal (no internet).
  • Short sessions focused on key questions.

Connected to the dashboard

The USSD service talks to the same central repository used by the Public Dashboard:

  • USSD request → application API → central repository.
  • Central repository → formatted response → USSD reply.
  • All requests can be logged as usage and transparency metrics.

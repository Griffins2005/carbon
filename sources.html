Verra

Carbon credit buyers (Public Dashboard)

The Carbon credit buyers section reports credit retirements and VCS project linkage from the Verra Registry — the authoritative public source for VCS projects, retirement transactions, VCU quantities, retirement dates, and official project names. CarbonWatch does not originate this data; it compiles Registry-aligned records for presentation.

  • Official source of record: Verra Registry (public project pages, retirement and transaction information).
  • Dashboard files (derived): data/buyers-transactions.json, data/buyers-summary.json, and data/buyers-coverage.json — JSON exports used by the site; metadata in each file cites the Registry.
  • Workbook: data/MASTER BUYERS CLEAN.xlsx — internal compilation used to generate the JSON; underlying retirement facts remain attributable to the Verra Registry.
  • Project names & IDs: VCS IDs and titles match registry.verra.org project listings.
